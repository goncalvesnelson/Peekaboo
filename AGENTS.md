# Peekaboo

Build the macOS app with Apple APIs directly, without third-party dependencies.

## Agent skills

### Issue tracker

Use GitHub Issues for specs and work items. Read `docs/agents/issue-tracker.md` before tracker operations.

### Triage labels

Use the default five triage labels. Read `docs/agents/triage-labels.md` when triaging or changing an issue's readiness.

### Domain docs

Use a single root `CONTEXT.md` and `docs/adr/`. Read `docs/agents/domain.md` before exploring or changing domain terminology and decisions.

### API research

Read `docs/research/native-macos-apis.md` before changing shortcut registration, conflict detection, or app activation. It separates verified behavior from checks still needed.
