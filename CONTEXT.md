# Peekaboo

Peekaboo gives selected Mac apps a shortcut that brings them forward or hides them.

## Language

**Assignment**:
A selected app paired with a shortcut. Multiple apps can have assignments, but a shortcut can belong to only one assignment.

**App toggle**:
Hide the assigned app when it is focused; otherwise bring it forward. Launch it if closed, leave minimized windows minimized, and preserve each window's Space.

**System shortcut conflict**:
An assignment uses the same combination as an enabled macOS system shortcut. The user can acknowledge the warning and attempt to use that combination, without a guarantee that macOS will accept or deliver it.
